# USB Captures Directory

Store your Wireshark/pcapng capture files here.

Recommended naming convention:
- `01_init.pcapng` — Initial device plug-in / driver startup
- `02_finger_valid.pcapng` — Enrolled finger tap (match success)
- `03_finger_invalid.pcapng` — Unenrolled finger tap (match rejection)
- `04_enrollment.pcapng` — Full enrollment sequence
